## 二、修复的问题

### 1. 毛发束参数从未接线（死参数）

`fur_strand_density` / `fur_strand_scale` 声明了、demo 和预设里也在设置，但 shader 里连 `strand` 字样都没有——用户调了完全没反应。

已接线：用 `fur_noise_texture` 在 `UV * fur_strand_scale` 的低频尺度上调制 `fur_mask`，让毛发成簇。这是本项目自有效果（lilToon 无 strand 参数）。

### 2. 导入映射指向不存在的参数

```gdscript
"bumpmap": "normal_map",          // 实际叫 normal_texture
"speculartex": "specular_texture"  // 项目根本没有这个参数
```

导入器"只写目标材质真实存在的参数"，所以这两条不会报错，会**静默丢弃**——法线贴图永远导不进来，高光贴图映射到一个永远不存在的名字。

已改 `normal_texture`；高光贴图删除并注明"原版属反射组，本项目受 SPECULAR 标量限制未实现"。

### 3. 状态标记参数缺少说明

`outline_enable_lighting` 在 shader 里零引用，实际是通过切换 shader 变体实现受光，这个参数只作为状态标记供 `set_outline_transparency` 读取。补了注释说明，避免以后被当成死参数删掉。

## 三、我自己犯的两个错（记录，避免重蹈）

**1. 凭 grep 片段推断出"除零 bug"**

看到 `saturate((value - border_min) / (border_max - border_min))` 就判定零模糊会除零。实际代码第 338 行是：

```glsl
clamp((value - border_min) / max(border_max - border_min + fwidth(value) * aa_strength, 0.0001), 0.0, 1.0)
```

有 `max(ε)` 兜底。**结论必须基于实际读取，不能基于搜索片段。**

**2. 扫描脚本范围不够，误报 4 个"缺失参数"**

`outline_lab.gd` 的 `depth_threshold` / `thickness` 等属于 `effects/post_outline_screen.gdshader`，不在 `shaders/` 目录。脚本只扫了 `shaders/`，于是误判。修正扫描根目录后归零。

## 四、未解决 / 需要决策

### 画质档位强制关闭用户功能

`quality/liltoon_quality.gd` 的 HIGH 档也写了 `use_matcap: false` / `use_sss: false` / `use_dissolve: false`。用户手动开了 MatCap，切一次画质档就被关掉。且档位只覆盖 7 个开关，Glitter / 自发光 / 二层阴影 / 毛发 / 各向异性 / 视差都不在控制范围内。

这不是 bug 而是设计选择（用参数开关模拟变体裁剪），但语义容易误导。建议要么改成"只降不升"（只关不开），要么在 UI 上标明档位会重置哪些项。

### 数学安全的一个已知项

`main_hsvg.w` 是 gamma 分量，`pow(abs(c), hsvg.w)` 在 `hsvg.w == 0` 且某通道为 0 时理论上得到 `pow(0,0)`。原版 `lil_common_functions.hlsl:350` 同样不设防，按"完全还原"原则保持一致，不额外加保护。
