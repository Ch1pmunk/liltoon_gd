## 未对齐（按类别）

### 独立功能线（2026-10-28 才纳入统计）

lilToon 除主材质 `lts.shader` 外，还有三条独立功能线。本矩阵长期只对照 `lts.shader` 的 Properties，**这三条线的特有属性从未进入过统计**——是发布前复查才发现的口径遗漏。

**`lts_ref.shader` 折射（4 项，可做）**

`_RefractionColor`、`_RefractionColorFromMain`、`_RefractionFresnelPower`、`_RefractionStrength`

实现方式：`hint_screen_texture` 采样屏幕 + 按法线扰动 UV。Godot 支持，工作量约半天，但需要渲染验证。

**`lts_gem.shader` 宝石（8 项，其中 4 项可做）**

- 可做：`_GemChromaticAberration`（RGB 三通道分离采样）、`_GemEnvColor`、`_GemEnvContrast`、`_GemParticleColor`
- 不做：`_GemParticleLoop`（需粒子系统联动）、`_GemVRParallaxStrength`（VR 专用）
- 复用：`_RefractionFresnelPower` / `_RefractionStrength` 与折射共用同一套实现

**`lts_fakeshadow.shader` 假阴影（1 项，可做）**

`_FakeShadowVector`：用一张平面贴图在地面画假阴影，与光照无关。工作量约半天。

**`lts_overlay.shader` 叠加层（30 项，不做）**

全部是 `_Pre*` 前缀的渲染状态（`_PreBlendOp`、`_PreZTest`、`_PreStencil*`、`_PreCull`、`_PreOffset*`），属 Unity 材质叠加层的通道配置，Godot 无对应机制。

**毛发线遗漏（6 项，可做）**

原版 `_Fur*` 去掉渲染状态后共 17 项，本项目实现 11 项，缺：

| lilToon | 用途 | 可行性 |
|---|---|---|
| `_FurMask` | 毛发遮罩（控制哪里长毛） | 可做，与 `fur_noise_texture` 同一套采样 |
| `_FurNoiseMask` | 噪声遮罩（控制噪声强度分布） | 可做 |
| `_FurRandomize` | 毛向量随机化（打散整齐感） | 可做 |
| `_FurVectorTex` | 毛向量贴图（用贴图指定方向） | 可做 |
| `_VertexColor2FurVector` | 顶点色转毛向量 | 可做 |
| `_FurTouchStrength` | 触摸交互（需运行时输入） | 需配套脚本，可做 |

> `_FurLayerNum` 不算缺失——本项目用 `fur_layers` 表达同一语义。

**本次确认的"可做但未做"合计 15 项**

```
折射        4  （_RefractionColor / ColorFromMain / Strength / FresnelPower）
宝石        4  （_GemChromaticAberration / _GemEnvColor / _GemEnvContrast / _GemParticleColor）
假阴影      1  （_FakeShadowVector）
毛发        6  （_FurMask / _FurNoiseMask / _FurRandomize / _FurVectorTex / _VertexColor2FurVector / _FurTouchStrength）
```

**明确不做**

- `_Pre*` 30 项：Unity 材质叠加层的通道配置（Blend / Stencil / ZTest / Cull / Offset）
- `_Fur*` 的约 20 项渲染状态：同上
- `_GemParticleLoop`（需粒子系统联动）、`_GemVRParallaxStrength` / `_TriMask`
- `_MatCapMul`：本项目用 `matcap_multiply` 表达同一语义，不算缺失

> **注**：本项目 shader 里 `refraction` / `gem_` / `fake_shadow` / `chromatic` 关键词零出现，`hint_screen_texture` 也未使用，确认折射与宝石完全未实现。
