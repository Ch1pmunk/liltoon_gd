## 一、阻塞级：本机完全无法出图

### [x] 1. `character` 场景（角色全材质）—— 2026-10-29 通过

- **场景**：`addons/liltoon_gd/demo/character.tscn`
- **命令**：`<godot> --path . res://addons/liltoon_gd/demo/character.tscn`
- **预期**：能看到完整角色——卡通硬分界的明暗、网格描边轮廓、毛发分层绒感、眼睛贴花贴合面部、金属件有反射
- **旧机现象**：启动画面之后**全程全黑**，日志无 `PipelineState` 错误、无 `ERROR`
- **旧机根因**：579 KB / 29 个 `sub_resource` / 11 个身体部件各挂 465 参数材质 / 4 个光源。初始化时串行编译 11 个材质，累计超过 Windows 的 2 秒 TDR 阈值 → 驱动重置 → 设备失效
- **新机结论**：RTX 4060 Laptop + Win11 + Godot 4.7.2 D3D12，一次通过；角色完整显示（卡通分界、描边、头发/眼睛/金属均可见），无 shader/管线错误。证据 `docs/evidence/阶段9/character_new_env.png`
- **注意**：`--quit-after` 无法规避旧机问题，控制帧数无效

### [x] 2. `dissolve_lab` 场景（溶解）—— 2026-10-29 通过

- **场景**：`addons/liltoon_gd/demo/dissolve_lab.tscn`
- **命令**：`<godot> --path . res://addons/liltoon_gd/demo/dissolve_lab.tscn -- shot`（加 `-- shot` 会截图到 `user://dissolve_lab.png`）
- **预期**：勾选「启用溶解」后拖动阈值滑块，物体被噪声逐渐吃掉，消失边缘有一圈边界色
- **旧机现象**：4 次尝试（16:12 / 17:22 / 17:28 / 17:39）全部 `DXGI_ERROR_DEVICE_REMOVED (0x887a0005)`，崩点固定在截图读回的 `buffer_create`
- **旧机已排除**：噪声贴图的 GPU 生成（改成 CPU 采样后仍崩）、分辨率（512×320 同样失败）
- **旧机根因**：未查明，倾向当时 GPU 已处于失效状态
- **新机结论**：加 `-- shot` 一次通过；遮罩 / UV 圆形 / 物体线性三种溶解形态可区分，边缘带与对照球正常。证据 `docs/evidence/阶段9/dissolve_lab_new_env.png`

### [x] 3. 后处理描边的深度边 —— 2026-10-29 已定位并修复

- **场景**：`addons/liltoon_gd/demo/outline_lab.tscn`
- **命令**：`<godot> --path . res://addons/liltoon_gd/demo/outline_lab.tscn -- shot`（输出 `user://outline_shot.png`）
- **预期**：四个球的轮廓出现橙色描边线
- **旧机现象**：**描边完全不出现**，面板却显示「启用描边」已勾选（静默失效）
- **根因（不是 D3D12 / 硬件）**：lilToon 的 opaque shader 在 alpha mask / dither / 溶解 / 毛发分支里写 `ALPHA`，Godot 据此把材质判为透明，**主渲染通道不写深度**，`depth_texture` 里没有角色与地面（探针全黑）。
- **修复**：三个 opaque 变体（`liltoon_opaque{,_double,_front}.gdshader`）加 `depth_prepass_alpha`，与 cutout / transparent 变体保持一致。
- **验证**：新机 D3D12 Forward+ 下四个球轮廓与地平线均出现橙色描边，2 px 与面板参数一致。证据 `docs/evidence/阶段9/outline_postprocess_fixed.png`
- **相关记录**：`DEVELOPMENT_PRINCIPLES.md` §9、`ROADMAP.md` RISKS、`docs/evidence/阶段9/说明.md`

## 二、观察级：需要长时间或人工目视

### [x] 4. 毛发动态效果 —— 2026-10-29 通过（视频帧比对）

- **场景**：`addons/liltoon_gd/demo/fur_multi_lab.tscn`
- **预期**：风力参数变化时毛束有摆动；重力参数改变时毛尖下垂方向变化
- **旧机限制**：单次渲染不能超过约 60 秒，观察动态效果要更久
- **新机验证**：`--write-movie` 录 90 帧（1.5 秒），首帧与末帧在毛尖区域有 671 个像素显著差异（最大通道差 699/765），确认风力驱动的顶点摆动生效。重力方向需人工拖滑块观察，未做

### [x] 5. 溶解的自动播放 —— 2026-10-29 通过（视频帧比对）

- **场景**：`dissolve_lab.tscn`，勾选「自动播放」
- **预期**：溶解阈值自动推进，物体平滑消失
- **新机验证**：新增命令行入口 `-- auto`（无 UI 也能回归）；录 180 帧（3 秒），首帧与中点/末帧分别有 3731 / 4929 个像素显著差异，阈值随时间推进，溶解形态连续变化
- **复现**：`<godot> --path . res://addons/liltoon_gd/demo/dissolve_lab.tscn --write-movie out.png --quit-after 180 -- auto`

### [x] 6. 变体外观 —— 2026-10-29 通过（场景实际为 4 个代表材质）

- **场景**：`addons/liltoon_gd/demo/variant_lab.tscn`
- **修正记录**：清单原写"13 个变体同时呈现"不准确。场景里只有 4 个对象：`opaque_double`（Double）、`transparent_premul`（Premul）、`opaque`（Triplanar）、`outline`（Backface 平面）；"13/17 个变体"指 shader 文件总数，由编译自检覆盖。
- **新机验证**：4 个对象外观符合语义——双面球可见内壁、预乘球半透明、三平面球条纹正确、背面平面只显示内壁。Cutout / A2C 由 `a2c_lab` 覆盖（左硬边、右 4× MSAA 平滑并透出橙底）。
- **`*_front` 变体**：无独立演示场景，仅编译自检通过，外观未人工目视

### [x] 7. `quality_lab` 三档 FPS —— 2026-10-29 已跑，结论：测试场景太轻，测不出差异

- **场景**：`addons/liltoon_gd/demo/quality_lab.tscn`
- **命令**：`<godot> --path . res://addons/liltoon_gd/demo/quality_lab.tscn -- bench`
- **新机结果**：high 2091 FPS / 0.48 ms，medium 2051 FPS / 0.49 ms，low 2115 FPS / 0.47 ms（540×360，单球）
- **结论**：RTX 4060 上该场景远未成为瓶颈，三档差异淹没在噪声里；**属测试设计问题**（场景太轻、分辨率太低），不是档位实现 bug。旧机结果同样只有 <2% 差异。若要真正量化档位收益，需要一个高面数 + 多材质 + 1080p 的基准场景，属后续工具改进项

## 三、已知偏差（不需要复验，但要知道）

| 项 | 说明 |
|---|---|
| `glitter_angle_randomize` / `glitter_normal_strength` | 闪点是程序化哈希噪声，旋转采样坐标几乎不改变统计分布，视觉差异远小于原版（原版的朝向随机作用于有形状的 `_GlitterShapeTex`）。见 `docs/evidence/阶段9/glitter_lab.png` |
| `main_hsvg.w == 0` 时的 `pow(0,0)` | 与原版 `lil_common_functions.hlsl:350` 同样不设防，按"完全还原"原则保持一致 |
| 多光源下 MatCap / Glitter 的受光 | 参数非 0 时逐光源重复采样贴图，开销随光源数线性增长（结果正确，只是慢）；参数默认 0，与原版一致 |

## 四、换机后的执行顺序建议

1. 先跑 `character`（阻塞级第 1 项）——它是唯一确定"新环境是否够强"的测试
2. 再跑 `dissolve_lab` 与 `outline_lab`（第 2、3 项）
3. 最后补观察级（第 4–7 项）
4. 每验完一项，把结论回填到本文件，并同步 `docs/evidence/阶段9/说明.md`

## 五、本机的验证边界（供参照）

```
能跑：单 shader 编译（20+ 次无异常）、少材质场景的 -- shot 截图（21 张）
不能跑：多材质 + 多光源场景的初始化（character）
不稳定：连续渲染超过约 60 秒、设备被移除后需重启才能恢复
```

硬件事实：`WHEA` 硬件错误 0 条，TDR 共 16 次（全部能自动恢复），说明**显卡本身没坏，是初始化负担超出其能力**。
