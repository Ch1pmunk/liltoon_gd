## 一、本轮已实现（17）

| liltoon | 本插件 | 说明 |
|---|---|---|
| `_AAStrength` | `aa_strength` | 原版用于 toon 阶跃的抗锯齿（不是 Alpha 边缘软化，也不是 A2C）：`fwidth(value)` 扩宽 1st/2nd/3rd 阴影与高光边缘；默认 1，0 关闭 |
| `_AlphaToMask` | `use_alpha_to_mask` + `liltoon_cutout_a2c*.gdshader` | Cutout 的 MSAA Alpha 覆盖；面板开关 + 预设键；变体按渲染面分三份 |
| `_MainTex_ScrollRotate` | `main_uv_scroll` + `main_uv_rotate` | 原版 vec4（滚动 xy、角度 z、角速 w）拆成两个 vec2；先旋转再叠加按时间取小数的滚动，作用于主色/法线/AO/Alpha 遮罩，贴花层不受影响 |
| `_MainTexHSVG` | `main_hsvg` | 原版 vec4（色相偏移/饱和度/明度/Gamma），按 `lilToneCorrection` 原式实现；默认 (0,1,1,1) 不改变颜色 |
| `_Reflectance` | `reflectance` | 反射率/F0，写入 Godot 的 `SPECULAR`；默认 0.5（此前固定为 1.0，反射偏强） |
| `_MainGradationTex` | `main_gradation_texture` | 1D LUT 逐通道查表，sRGB 空间采样后转回线性（`lilGradationMap` 原式） |
| `_MainGradationStrength` | `main_gradation_strength` | 渐变强度 0..1 |
| `_MainColorAdjustMask` | `main_color_adjust_mask` | R 通道控制 HSV/渐变整套调整的生效比例 |
| `_BackfaceColor` | `backface_color` | 双面材质背面按 Alpha 混入该颜色（在光照前替换 ALBEDO，近似原版的后置混合） |
| `_ShiftBackfaceUV` | `shift_backface_uv` | 背面 UV 加 (1,0)，配合图集使用 |
| `_UseDither` | `use_dither` | 按屏幕像素查 4×4/8×8 图案并二值化 ALPHA |
| `_DitherTex` | `dither_texture` | 抖动图案（点采样、重复） |
| `_DitherMaxValue` | `dither_max_value` | 255 为标准抖动，数值越小裁切越强 |
| `_GSAAStrength` | `gsaa_strength` | 按法线屏幕导数抬高 `ROUGHNESS`，柔化反射边缘 |
| `_MetallicGlossMap` | `metallic_gloss_map` | R=金属度、A=光滑度，按主 UV 采样，乘到 `METALLIC` / `ROUGHNESS` |
| `_SmoothnessTex` | `smoothness_texture` | R 通道乘到光滑度上 |
| `_ReflectionApplyTransparency` | `reflection_apply_transparency` | `SPECULAR`（F0）乘 ALPHA，透明材质的反射随透明度淡出 |
| `_SpecularNormalStrength` | `specular_normal_strength` | 高光用法线在几何法线与扰动法线间插值；0 时法线贴图不改变高光位置，默认 1 |
| `_ReflectionColorTex` | `use_reflection_color_tex` + `reflection_color_tex` | 近似：原版乘反射颜色 RGB，这里 `SPECULAR` 是标量，只能按 Rec.601 亮度缩放反射强度 |

## 四、接受差距（42）

| 项 | 原因 |
|---|---|
| `_IDMask1`、`_IDMask2`、`_IDMask3`、`_IDMask4`、`_IDMask5`、`_IDMask6`、`_IDMask7`、`_IDMask8`、`_IDMaskIndex1`、`_IDMaskIndex2`、`_IDMaskIndex3`、`_IDMaskIndex4`、`_IDMaskIndex5`、`_IDMaskIndex6`、`_IDMaskIndex7`、`_IDMaskIndex8`、`_IDMaskPrior1`、`_IDMaskPrior2`、`_IDMaskPrior3`、`_IDMaskPrior4`、`_IDMaskPrior5`、`_IDMaskPrior6`、`_IDMaskPrior7`、`_IDMaskPrior8`、`_IDMaskCompile`、`_IDMaskFrom`、`_IDMaskIsBitmap`（27） | liltoon 的 ID 遮罩是一套编辑器生成 + shader 分支的子系统；Godot 可用顶点色/UV 通道替代，但接口与烘焙流程完全不同，暂不实现 |
| `_ReflectionCubeTex` | 逐材质自定义反射立方体贴图；Godot 环境反射走环境 / ReflectionProbe，当前探针不生效（见 RISKS） |
| `_ReflectionCubeOverride` | 同上，开启自定义 cubemap 的开关 |
| `_ReflectionCubeColor` | 同上，自定义 cubemap 的染色 |
| `_Invisible` | Unity 编辑器用的“材质不可见”标记，运行时无行为；Godot 用节点 `visible` 或透明度控制 |
| `_OffsetFactor` | 多边形偏移；Godot 无 per-material offset，只能用 `depth_offset` 近似，语义不同 |
| `_OffsetUnits` | 同上 |
| `_ReflectionColor` | Godot 无法逐材质给环境反射染色（`SPECULAR` 是标量 F0） |
| `_ReflectionNormalStrength` | 无法单独为反射指定法线，环境 IBL 走引擎自动流程 |
| `_ReflectionBlendMode` | 引擎反射混合固定为加法，无逐材质混合接口 |
| `_EnvRimBorder` / `_EnvRimBlur` | 仅在 Unity BRP + VRChat 光照体积（`VRC_LIGHT_VOLUMES_INCLUDED`）下使用，Godot 无对应子系统 |
| `_VertexLightStrength` | Unity 顶点光照强度，Godot 无顶点光照阶段 |
| `_lilDirectionalLightStrength` / `_BeforeExposureLimit` | 仅在 HDRP 下定义，当前管线无用例 |
| `_lilShadowCasterBias` | Godot 无独立阴影 pass 的位置偏移接口，只能整体 `depth_offset` 近似 |
| `_ShadowPostAO` | 需要把边界遮罩从阶跃后乘改为阶跃前乘，会改变现有全部材质外观，留到有渲染验证时再评估 |
| `_ShadowColorType` | LUT 阴影色采样（`LIL_FEATURE_SHADOW_LUT`），属于原版的额外能力，不在对齐主线 |
| `_RimBlendMode` | 原版在**最终颜色**上按 Normal / Add / Screen / Multiply 混合；Godot 的 `light()` 只能往 `SPECULAR_LIGHT` 累加，等价实现只有 Add，其余三种无落点 |
