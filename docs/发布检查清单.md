# 发布前检查清单

每次发版前从头跑一遍。分三层：**自动检查**（几秒到几分钟）、**人工目视**（需要 GPU 与眼睛）、**换机待验**（本机做不了）。

---

## 一、自动检查（必跑，全绿才能发）

### 1. 冒烟测试

```powershell
powershell -ExecutionPolicy Bypass -File tools\smoke.ps1 -TimeoutSec 120
```

**期望**：`冒烟测试通过` + `SMOKE_DONE`，且耗时在 10 秒内。

**覆盖**：每个 uniform 有中文描述、进预设 `BASE`、预设往返一致、越界校验、预设缩略图可加载。

**超时说明**：脚本 120 秒强杀。若被杀，看它打印的尾部输出——通常是某个 `.gd` 编译失败。

### 2. 参数对齐矩阵

```powershell
python tools/gen_alignment_matrix.py
```

**期望**：数字与 `docs/参数对齐矩阵.md` 头部一致。

**若数字变了**：说明加了/删了参数但没更新文档，跑 `--write` 刷新，并检查新参数是否登记了归属。

### 3. 默认值一致性

```powershell
python tools/compare_defaults.py
```

**期望**：`默认值不一致 0 项`。

**若非 0**：逐条对比 `lts.shader` 的 Properties，判断是"我们写错了"还是"有意差异"。后者要在 §9 记录。

### 4. 发布前静态审计

```powershell
python tools/audit_release.py
```

**期望**：`问题合计：0`。

**覆盖**：`res://` 路径存在性、`class_name` 唯一性、`plugin.cfg` 入口、文档里的文件引用、`TODO/FIXME` 残留。

**补充说明**：该脚本不启动 Godot、不碰 GPU，可在任何时候跑。它查不出视觉正确性，只保证"引用的东西都在、没有半成品标记"。

### 5. 变体编译（分批，注意频率）

```powershell
# 先看索引
powershell -ExecutionPolicy Bypass -File tools\check_all_shaders.ps1 -ListOnly

# 逐进程跑，一批 5 个，批间静默几分钟
powershell -ExecutionPolicy Bypass -File tools\check_all_shaders.ps1 -Start 0 -End 4 -DelaySec 30
```

**期望**：**25 个** shader 全部 `OK`（23 个主材质/描边 + 2 个后处理描边，后两个的索引是 23、24）。

**重要**：不要背靠背连跑。这台机器上连续渲染约 60 秒会触发驱动超时（TDR），表现为黑屏。用脚本 + 间隔。

## 二、人工目视（有 GPU 的环境）

### 5. `showcase.tscn` —— 整体观感

```powershell
<godot> --path . res://addons/liltoon_gd/demo/showcase.tscn
```

**看**：5 个预设球（default / skin / hair / cloth / metal）的外观是否符合预设名，cutout 是否有硬边，transparent 是否半透明，角色是否有描边。

**注意**：该场景**不含** MatCap / Glitter / 贴花，这三类要看下面的 lab。

### 6. 按子系统抽查 lab 场景

| 子系统 | 场景 | 看什么 |
|---|---|---|
| MatCap 受光/阴影 | `matcap_shade_lab` | 基准不受光、第二球染暖色、第三球上半被阴影压暗 |
| MatCap UV1 / 自定义法线 | `matcap_uv_lab` | 条纹从弧形变直、探针球全绿、法线球条纹偏移 |
| 第二槽 | `matcap_2nd_lab` | 环形条纹、受光染色、阴影压暗、环心偏移 |
| Glitter | `glitter_lab` | 颜色贴图球左蓝右红，闪点均匀 |
| 各向异性 | `aniso_lab` | 月牙形高光、遮罩加宽、切线贴图改方向 |
| 法线/高光 | `normal_specular_lab` | 高光法线 0 是圆斑、1 是不规则 |
| 阴影全量 | `shadow_full_lab` | 六球六种表现各不相同 |
| 距离淡出 | `fade_rim_lab` | 右球有青色边缘光晕 |
| A2C | `a2c_lab` | 左阶跃右平滑，右侧透出橙底 |
| 毛发 | `fur_multi_lab` | 绒感、无硬壳感 |
| 描边 | `outline_lab` | 球体轮廓有橙色描边（**当前已知不生效**，见 RISKS） |

**单次运行控制在 60 秒内**，超时会 TDR。

## 五、历史教训（每次发版前重读一遍）

| 教训 | 出处 |
|---|---|
| "无报错"不等于"有画面"：黑屏不产生日志 | character 两次测试均"通过"但实际全黑 |
| 凭印象判断默认值会错：`_MatCapEnableLighting` 原版是 1，曾误设 0 并声称"与原版一致" | P9 默认值对比 |
| 脚本扫描范围要够：漏了 `effects/` 目录导致误报 4 个"缺失参数" | 参数名一致性检查 |
| 片段不能代替全文：凭 grep 片段判定"除零 bug"，实际代码有 `max(ε)` 保护 | `lil_tooning_scale` |
| 字典键重复会让整个脚本编译失败，而依赖它的测试脚本会卡死不退出 | `preset_library.gd` |
